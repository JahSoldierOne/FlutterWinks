# FlutterWinks
Flutter Winks by Mimi beauty spar

## Deployment

To publish this static site, select **Settings > Pages > GitHub Actions** as the build and deployment source in the repository settings. The workflow in `.github/workflows/pages.yml` then deploys the site whenever changes are pushed to `main`.

After the workflow completes, the site will be available at https://jahsoldierone.github.io/FlutterWinks/.
